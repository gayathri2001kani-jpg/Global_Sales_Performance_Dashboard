# Global Sales Performance Dashboard – Power BI

## 📊 Project Overview

This project presents an interactive Global Sales Performance Dashboard developed using Microsoft Power BI. The dashboard provides insights into sales, revenue, profit, customers, products, and regional performance.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Star Schema
* Data Visualization

## 📌 Key Analysis

* Total Sales and Revenue
* Total Profit
* Customer Performance
* Product Performance
* Regional Sales Analysis
* Sales and Profit Trends
* Key Performance Indicators (KPIs)

## 📈 Dashboard Features

The dashboard uses interactive charts, KPIs, filters, and slicers to help users analyze global sales performance and identify important business insights.

## 🗂️ Data Model

The project uses a **Star Schema** consisting of fact and dimension tables to create an efficient and organized data model.

## 🎯 Project Objective

The objective of this project is to transform raw sales data into meaningful business insights and support data-driven decision-making through an interactive Power BI dashboard.
